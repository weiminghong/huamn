# Qwen-VL Token-Head Human Parser (v1)

This directory contains a first runnable scaffold for the hybrid decoder requested for COCO-UniHuman v1:

- JSON is generated by the LLM decoder and can be constrained by guided JSON decoding during evaluation.
- `<box>` uses the hidden state at the generated token and an MLP head to decode normalized body boxes.
- `<pose>` uses the hidden state at the generated token and an MLP head to decode COCO-17 keypoints.
- `<seg>` is a LISA-style mask-token hook. The current Stage1 v1 training path uses the official COCO-UniHuman v1 annotation JSON, where train annotations contain valid per-person segmentation masks. Val annotations also contain polygon segmentations even though `valid.segmentation` is 0, so official segm evaluation must use the polygon GT explicitly instead of treating v1 as unlabeled for segmentation.
- `gender` and `age` are normal structured JSON fields generated by the LLM.


## v1 reporting scope

For COCO-UniHuman v1 zero-shot reporting, use only three tasks:

- body box detection
- gender classification
- age estimation

Zero-shot v1 reporting is limited to body box, gender, and age. Stage1 finetuning/evaluation additionally trains and reports pose and segmentation heads from the official annotation JSON. Gender and age remain structured JSON fields optimized by language-model cross-entropy with missing labels masked from the supervised value tokens. Age `-1` is counted as missing coverage, not silently removed from the denominator.

## Example training command

Do not launch this while another full evaluation owns the target GPU.

```bash
cd /home/weiminghong/humanslot
CUDA_VISIBLE_DEVICES=3 /home/weiminghong/yes/envs/human_v2/bin/python -u human_lisa_qwen_v1/train_stage1_v1.py \
  --train-ann /share2/program/weiminghong/coco/unihuman_label/coco_unihuman_train_v1.json \
  --train-image-root /share2/program/weiminghong/coco/train2017 \
  --val-ann /share2/program/weiminghong/coco/unihuman_label/coco_unihuman_val_v1.json \
  --val-image-root /share2/program/weiminghong/coco/val2017 \
  --model /share2/program/weiminghong/model/Qwen2.5-VL-3B-Instruct \
  --output-dir /share2/program/weiminghong/humanslot_outputs/lisa_qwen_v1/stage1_v1_full_singlebackward_YYYYMMDD_gpu3/train \
  --epochs 1 --batch-size 1 --grad-accum-steps 4 --max-length 5000 \
  --trainable-families visual language box pose mask \
  --missing-attribute-loss-weight 0 --no-pose-box-jitter --no-split-ce-task-backward \
  --bf16
```

## Current limitations

- This is a trainable VLM-token-head baseline. `<seg>` currently uses a lightweight person mask decoder from the generated `<seg>` hidden state plus visual tokens, not a full SAM/SAM2/Sapiens decoder.
- Segmentation training uses the official train polygons. For val, polygon GT is present but `valid.segmentation` is 0, so the official segm evaluator path must intentionally include those polygons.
- For paper-facing evaluation, attribute/action/relation AP should use task-specific ignore matching for persons whose sublabels are missing.
