# Stage2 (Head-Based Multi-Task)

This folder contains the `mm`-style task training components created earlier:

- `box` with `mmdet`
- `pose` with `mmpose`
- `parsing` with `mmseg`

These are head-based discriminative training components and correspond to your
`stage2` idea (or later distillation stage), not the pure VLM text generation
`stage1`.
